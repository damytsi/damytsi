Durante minha trajetória acadêmica, desenvolvi o projeto **“Estudo Bibliométrico – Análise Bibliográfica da FICE IFC Camboriú”**, sob orientação do professor Angelo Augusto Frozza.  

O objetivo foi analisar a produção científica do evento em suas 11 edições (2012–2023), construindo um banco de dados completo para subsidiar análises futuras e acompanhar a evolução da feira.  

O projeto envolveu:
- Organização e estruturação de dados  
- Criação de indicadores bibliométricos  
- Desenvolvimento de uma base sólida para novas pesquisas  

🏆 O trabalho recebeu **Menção Honrosa na FICE** e foi publicado nos anais da **MICTI (Mostra Nacional de Iniciação Científica e Tecnológica Interdisciplinar)**, consolidando sua relevância acadêmica.
